Die SHA256/512-Hash-Funktionen werden durch die Crypto API des Web Browsers realisiert.

Elliptische Kurven Kryptographie wird durch elliptic und einer angepassten Implementierung der secp224k1-Kurve realisiert. Hierbei kommen je nach Verfahren und Ladestations- bzw. Smart-Meter-Hersteller unterschiedliche elliptische Kurven zum Einsatz.

## Reporting a Vulnerability

Please **do not** report security vulnerabilities through public GitHub issues.

Instead, please use GitHub's private vulnerability reporting ("Report a vulnerability" in the Security tab of this repository) or send an encrypted report via email to `info@graphdefined.com` (PGP Key ID `0xC6CBE6A4`, Fingerprint `3CD0 09F4 0008 616A 91D0 7646 2DD3 B48B C6CB E6A4`).

Vulnerabilities will be fixed as soon as possible, but remember that this software has to be "certified" by German regulators to become a "lawful" software for the German Eichrecht. This can take days, weeks, months...
